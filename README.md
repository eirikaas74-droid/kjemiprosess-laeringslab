# Kjemiprosess læringslab

Ressurser og læringsaktiviteter for Vg2 kjemiprosess- og laboratoriefag (KPL02-01).

Nettstedet er statiske HTML-sider og publiseres med GitHub Pages.

## Struktur

```
index.html              Forside med temaoversikt
prosessikkerhet/        Tema: prosessikkerhet
vaeske/                 Tema: væske i prosessindustrien (6 deler)
```

## Legge til et nytt tema

1. Lag en ny mappe, for eksempel `pid/`, med en `index.html`.
2. Legg temaet inn i `TOPICS`-listen i `index.html` og sett `live: true`.
3. Commit og push. GitHub Pages oppdaterer siden i løpet av et par minutter.

## Publisere med GitHub Pages

Settings → Pages → Source: «Deploy from a branch» → Branch: `main`, mappe `/ (root)`.
